## 压缩阈值语义
- **结论**：只读审计确认预压缩已采用模型有效预算乘 ContextCompactTriggerPercent；旧测试仍断言固定 token 阈值取最小值，语义过时，本轮未改代码。
- **约束**：百分比≤0仅关闭 token 触发，轮次上限及 Force 硬预算路径独立有效；预算与启用后的阈值均有4000下限。（重要）
- **推算**：窗口200000、输出4000时，扣13000预留后80%阈值为146400；窗口32000同条件阈值12000，10%受下限约束为4000。
- **结论**：预压缩已采用模型有效预算×百分比；ContextCompactTriggerPercent=0仅关闭 token 触发，轮次上限仍有效，不能恢复旧 min 固定阈值语义。
- **结论**：ContextCompactTrigger 已不参与阈值计算；ContextMaxInputTokens 仍限制 custom 系统槽位及全量附件预算，不应与压缩触发混同。
- **测试迁移依据**：窗口200000、输出4000、缓冲13000、比例80%时阈值146400；窗口32000时12000；预算与阈值均设4000下限。
